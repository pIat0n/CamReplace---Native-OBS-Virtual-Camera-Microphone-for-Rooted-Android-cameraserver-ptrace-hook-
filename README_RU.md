# CameraReplace

[English](README.md) | **Русский**

<img width="1284" height="762" alt="CameraReplace" src="https://github.com/user-attachments/assets/bc1f329d-c67a-43de-8c9b-c9b75c097fff" />

CameraReplace — это Windows-приложение и набор нативных компонентов для Android, позволяющие передавать видео и звук из OBS на тестовое Android-устройство с root-доступом через USB. Windows-приложение принимает RTMP-поток, передаёт медиаданные через локальные ADB-туннели и управляет подачей потока и жизненным циклом хуков на смартфоне.

В этом репозитории опубликована открытая версия для разработки. В ней нет сервера лицензирования, авторизации через Telegram, загрузчика отчётов об ошибках, рабочих учётных данных, проекта VMProtect, проверки launch ticket и закрытого release-конвейера. Защищённый медиаканал между компьютером и устройством согласуется локально и не требует сервера.

## Скачать

Готовые Windows-версии публикуются на странице [GitHub Releases](https://github.com/pIat0n/CamReplace---Native-OBS-Virtual-Camera-Microphone-for-Rooted-Android-cameraserver-ptrace-hook-/releases). Исходный код также можно полностью собрать самостоятельно при помощи `build.bat`, как описано ниже.

## Возможности

- Приём H.264- и AAC-потоков OBS/RTMP в Windows.
- Передача сжатого H.264-видео или кадров NV21 без сжатия.
- Передача звука микрофона в формате PCM.
- Встроенные ADB и Android arm64-компоненты в одном Windows EXE-файле.
- Управление заменой камеры, микрофона и неподвижного изображения.
- Предпросмотр в реальном времени, поиск устройств, диагностика скорости USB и журналы сеанса.

## Требования

- Windows 10 или Windows 11 x64.
- CMake 3.24 или новее и Ninja, доступные через `PATH`.
- Android SDK Platform Tools.
- Android NDK `29.0.14033849`.
- Набор инструментов LLVM-MinGW x86_64 MSVCRT.
- Тестовое Android-устройство arm64-v8a с root-доступом и Android API 21 или новее.
- OBS Studio как источник медиапотока.

Скрипт сборки автоматически проверяет стандартные расположения SDK. Если инструменты установлены в другие папки, перед запуском задайте переменные окружения:

```bat
set ANDROID_SDK_ROOT=D:\Android\Sdk
set ANDROID_NDK_ROOT=D:\Android\Sdk\ndk\29.0.14033849
set LLVM_MINGW_ROOT=D:\Toolchains\llvm-mingw
```

## Сборка

Клонируйте репозиторий и запустите единственный корневой скрипт:

```bat
build.bat
```

Скрипт проверит необходимые инструменты, соберёт Android arm64-компоненты, встроит их вместе с ADB в Windows-приложение и сохранит готовый файл по адресу:

```text
build\host-dev-dev\bin\CameraReplace.exe
```

Для сборки не нужны сервер, закрытый ключ, файл окружения, VMProtect или заранее собранные артефакты проекта.

## Структура проекта

- `host/` — Windows-интерфейс, приём RTMP, предпросмотр, транспорт и управление через ADB.
- `android/` — инжектор, процесс подачи медиаданных, хук камеры и хук аудио.
- `common/` — протокол локального защищённого канала и встроенная криптография.
- `imgui/` — исходный код Dear ImGui для Windows-интерфейса.
- `third_party/` — исходный код зависимостей, необходимых для сборки.
- `scripts/` и `toolchains/` — реализация, которую использует `build.bat`.
